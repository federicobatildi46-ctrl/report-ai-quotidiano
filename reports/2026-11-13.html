Claude Code v2.1.323: Code Mode sperimentale e novità sui plugin
✅ Ufficiale Release note ufficiale di Claude Code su GitHub.
Claude Code 2.1.323 introduce Code Mode, una modalità sperimentale opt-in in cui Claude scrive JavaScript per richiamare i suoi strumenti. Arrivano anche controlli di versione per i plugin e diversi fix di stabilità.
