Guida di Addy Osmani: con /ship Claude Code segue la PR dopo l'apertura
✅ Ufficiale Articolo sul blog ufficiale di Claude (claude.dev), scritto da Addy Osmani.
Il blog di Claude descrive come delegare a Claude Code il lavoro dopo l'apertura di una pull request: CI fallite, commenti di review, conflitti. Il lancio Claude Ship comprende tre agenti: Code Review, PR Steward e Claude Approvals.
  • Code Review è disponibile per tutti; PR Steward e Claude Approvals sono in beta.
  • `/code-review` controlla commit e modifiche non committate cercando bug di correttezza.
  • `/ship` apre la PR, la rivede e gestisce ciò che torna indietro.
  • `/steward` segue una PR già aperta; /ship funziona anche senza admin.
Perché ti serve. È un flusso di lavoro che puoi imparare subito e proporre a clienti con team di sviluppo, oppure raccontare in un contenuto.

fast-anything: un agente riscrive in Rust solo le parti lente della tua app
📦 Dal progetto Stelle (3.673), data di creazione e licenza MIT verificate su GitHub; le funzioni sono dichiarate dagli autori, non provate.
Questa repo trova le funzioni più pesanti di un'app lenta e le fa riscrivere in Rust a un agente AI come Claude. Poi controlla che il risultato sia identico e le sostituisce, in modo reversibile.
  • Cosa fa: individua le funzioni lente e le riscrive in Rust, verificando l'identità del risultato.
  • Come si prova: `npm i -g @el4cteo/fast-anything` o `cargo install fast-anything`; serve rustup.
  • Poi: `fast-anything go --agent claude -- python app.py`.
  • Costo: gratis, licenza MIT. È più adatto a chi usa il terminale.
Perché ti serve. Per chi ti segue è una dimostrazione concreta di un agente che velocizza il codice, da provare prima di raccontarla.
