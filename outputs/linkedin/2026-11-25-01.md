# Post LinkedIn: Claude Code 2.1.332, skill dai server MCP e nuovo hook di controllo

## Post
Il tuo collaboratore più esperto va in ferie. Con lui partono 100 "come si fa questa cosa?" 🙃

Con Claude Code 2.1.332 arriva un pezzo interessante: le skill dai server MCP (in beta).

Tradotto, amico: una skill è un foglio di istruzioni che l'AI segue per fare un lavoro a modo tuo. MCP è la "presa" che collega Claude a strumenti e servizi esterni.

Da ora quelle istruzioni possono arrivare direttamente dal server collegato. Le trovi nel menu "/" con il nome del server davanti.

Un po' come Neo in Matrix che scarica il kung fu. Con molte meno acrobazie.

La seconda novità riguarda il controllo:

→ Comandi — una skill locale può contenere comandi che partono sul tuo computer mentre si carica.
→ Filtro — un nuovo "hook" (una regola automatica) può rifiutarli prima che vengano eseguiti.
→ Regia — le regole del filtro le decidi tu, e qualcuno le deve configurare bene.

Tutto automatico? No.

⚠️ Le skill dai server sono in beta, e io devo ancora provarle. La prima cosa che testerò: una procedura semplice, scritta una volta e richiamata dal menu.

E se la procedura è scritta male, l'AI la segue male con grande disciplina 🤣

Perché conta per te? 👇

Se hai uno studio o un'agenzia con 12 persone, forse conosci la scena:

• 2-3 ore a settimana a persona a cercare file, istruzioni e ultime versioni
• 3-4 ore a settimana del titolare a rispondere sempre alle stesse domande interne
• circa 4 ore a settimana tra pagamenti e fatture, spesso con passaggi da ricostruire ogni volta

Con un sistema su misura, dove le procedure stanno in un posto solo e l'AI le richiama, puoi puntare a recuperare il 30-40% del tempo di ricerca: circa 7-14 ore a settimana su tutto il team ⚙️

Sono stime indicative: per sapere quanto vale nel tuo caso serve un'analisi fatta sul tuo lavoro.

Morale della favola: prima metti ordine in come lavori, poi lo fai eseguire all'AI.

Lei propone, tu approvi. Human in the loop, sempre 🤓

Commenta "SKILL" e ti mando in privato, gratis, uno schema di una pagina per scrivere la tua prima procedura in modo che un'AI possa seguirla 👇
