# OpenMotion: ricostruire video di tendenza come motion graphics modificabili

## In una frase

OpenMotion è uno studio video open source (licenza Apache-2.0, gratuito) che, con il tuo agente AI locale, ricostruisce un video di riferimento come motion graphics modificabili, con i colori e i testi del tuo brand, e poi lo esporta in MP4. La fonte lo presenta come alternativa open source a Claude Motion e CapCut.

## I concetti chiave

- **Video agentico full-stack.** Il video viene "codificato con HTML". L'agente scompone il riferimento, ricostruisce inquadrature e transizioni e genera gli asset che mancano. Poi regoli i tempi nello Studio ed esporti l'MP4 dallo stesso progetto.
- **BYOA e BYOK.** *Bring Your Own Agent* e *Bring Your Own Keys*. OpenMotion è gratuito, ma lavora nel tuo agente locale (Claude Code, Codex, WorkBuddy tra quelli citati) con le tue chiavi API. Le fonti non dicono quanto costino le chiavi dei modelli esterni: è un costo che può esserci a parte.
- **Motion.md.** È un formato Markdown introdotto da OpenMotion per descrivere ordine delle inquadrature, tempi e transizioni. Serve a condividere come funziona un video, shot per shot.
- **Studio.** L'editor locale con la timeline, dove correggi i tempi. Si apre dall'indirizzo (`studioUrl` o `previewUrl`) stampato all'avvio.
- **Modelli per gli asset.** Il README cita GPT Image 2.6 per le immagini, Seedance 2.5 per le inquadrature video, Suno per la musica ed Eleven v4 per la voce.
- **Analogia.** Pensa a un montatore che guarda un video di tendenza, lo rifà da zero come "ricetta" modificabile e ti lascia cambiare ingredienti (colori, testi) senza ricominciare.

Nota sulle fonti: tutto ciò che segue viene dal README ufficiale del repository. La ricerca web lo classifica come "non ufficiale", ma qui non ci sono opinioni di creator da distinguere. Le affermazioni di marketing ("alternativa a CapCut") sono dichiarazioni degli autori, non test indipendenti.

## Passo passo

**Via A: installare la Skill nel tuo agente**

1. Nel terminale esegui:
   ```sh
   npx skills add nexu-io/openmotion --skill openmotion
   ```
2. Chiedi all'agente: *"Use OpenMotion to install and connect the local Studio and MCP, then help me make a video."*
3. Attenzione: installare solo la Skill copia le istruzioni, ma **non** installa lo Studio né collega l'MCP. Lo fa l'agente quando glielo chiedi al punto 2.
4. A setup finito, l'agente apre la libreria di template locale con tre schede di anteprima. Scegli un'anteprima, premi **Recreate template**, poi invia il tuo brief.

**Via B: dal repository (sorgente)**

1. Servono Git, npm e Node.js. Il README indica Node.js 26.11.1 nel testo, mentre il badge riporta "Node.js 22.18+": le versioni non coincidono nel testo che ho, quindi controlla `package.json`.
2. Il campione indica anche Chrome e FFmpeg come requisiti (secondo la notizia del report).
3. Comandi:
   ```sh
   git -c filter.lfs.process= -c filter.lfs.smudge= -c filter.lfs.required=false clone --depth 1 --single-branch --branch main https://github.com/nexu-io/openmotion.git
   cd openmotion
   npm ci
   npm run build:studio
   npm start
   ```
4. Apri l'indirizzo `studioUrl` o `previewUrl` stampato all'avvio e scegli **Template library**.
5. Per collegare il tuo agente a questa copia, segui la sezione "source setup and MCP configuration" del README (non inclusa nel testo che ho: non documentato nelle fonti).

**Altre opzioni documentate**

- Installazione da ChatGPT Marketplace con un clic (non necessaria se usi Claude Code).
- App npm pubblicata con Studio precompilato: si chiede all'agente di leggere la pagina di installazione indicata nel README. Le versioni pubblicate possono essere indietro rispetto al repository.
- Importare un progetto HyperFrames in ZIP: **All projects → Import projects**. Crea una copia indipendente e richiede una struttura nativa supportata.

**Prompt per ricostruire un video**

Il README non fornisce un prompt esatto per la ricostruzione, oltre a caricare un video di riferimento o incollare un link social e dare il tuo brief. Un esempio mio, da adattare (non è tratto dalle fonti): *"Ricostruisci questo video con i colori [HEX] e i testi che ti allego, mantenendo ritmo e transizioni."*

Dettagli non documentati nelle fonti che ho: formati di esportazione oltre MP4, durata massima dei video, tempi di rendering, costi delle chiavi dei modelli.

## Applicalo a un cliente

**Caso:** uno studio dentale o un personal trainer che vede un video di tendenza nel suo settore e vorrebbe un contenuto simile.

1. Raccogli il brand kit del cliente: colori, font, logo, testi (offerta, claim).
2. Carica il video di tendenza o incolla il link social.
3. Chiedi all'agente di ricostruirlo con colori e testi del cliente.
4. Nello Studio correggi i tempi e controlla le inquadrature.
5. Esporta l'MP4 per Reel e Shorts.

**Cosa proponi:** un pacchetto "video di tendenza in versione tuo brand", ripetibile ogni settimana.
**Risultato atteso:** secondo la notizia, rifai un video di tendenza in pochi passi. Rispetto ai tempi reali non ho dati: provalo su un caso tuo prima di promettere scadenze.

## Idea di contenuto

**Short o Reel:** schermo diviso, a sinistra un video di tendenza e a destra la sua ricostruzione con i colori di un cliente. Gancio: "Ho rifatto questo video virale con il brand di un cliente, gratis". Chiudi con CTA a parola chiave per ricevere il link. Dichiara che l'originale è di un altro creator e cita la fonte.

## Errori comuni e limiti

- Pensare che installare la Skill basti: serve poi chiedere all'agente di installare Studio e MCP.
- Dimenticare che le chiavi API dei modelli (immagini, video, musica, voce) sono tue: costi e limiti dipendono dai provider, non documentati qui.
- Versioni di Node discordanti nel README (26.11.1 nel testo, 22.18+ nel badge): verifica `package.json`.
- Le versioni npm pubblicate possono essere indietro rispetto al repository.
- **Diritti d'autore:** ricostruire un video altrui con i tuoi testi può porre problemi di copyright. Le fonti non lo trattano: valutalo prima di usarlo per un cliente.
- Il README è marketing: non ci sono test di qualità indipendenti nelle fonti.
