# Claude Code Code Mode: meno token con più azioni in un solo programma

## In una frase

Code Mode è una modalità sperimentale di Claude Code in cui Claude, invece di chiedere le azioni una alla volta, scrive un piccolo programma JavaScript che le esegue tutte insieme sul tuo computer e restituisce solo il risultato finale. Conta perché, nei lavori con tanti file e tante azioni, può ridurre molto il consumo di token (secondo il creator, fino a 10x).

## I concetti chiave

**Fatti (fonte ufficiale: note di rilascio v2.1.329)**
- La v2.1.329 aggiunge il supporto per attivare Code Mode **mentre sono attivi eventi e metriche OpenTelemetry**. Ogni chiamata a strumento fatta dal codice invia i suoi eventi. Il *tracing* invece continua a tenerlo disattivato.
- Nella stessa versione sono corretti alcuni bug di Code Mode:
  - uno script che riempiva la memoria della macchina in un ciclo infinito: ora viene fermato a un limite;
  - le modifiche già completate da uno script e il comando fermato con Esc, che venivano nascosti e persi all'uscita.
- La versione corregge anche molti altri problemi (`/teleport`, `/code-review`, login, MCP e altro). Qui ci interessa soprattutto Code Mode.

**Opinioni e spiegazioni del creator (Giovanni Beggiato, non ufficiale)**
- **Token**: l'unità con cui Claude conta quanto testo legge e scrive. Più ne consumi, prima finisci l'abbonamento (o spendi di più, se paghi a consumo).
- **Contesto**: tutta la conversazione che Claude si porta dietro (richieste, letture, risposte, strumenti usati).
- **Modalità normale**: ogni azione è una chiamata a uno strumento (es. "leggi questo file"). Il risultato torna per intero nel contesto e Claude rilegge tutto prima di decidere il passo successivo. Il contesto cresce a ogni giro.
- **Analogia dell'archivio**: in modalità normale chiedi all'assistente una cartella alla volta e, a ogni richiesta, rileggi tutte le precedenti. Con Code Mode gli dai un foglio di istruzioni ("apri tutte e 30 le cartelle, segna solo le cose aperte, torna con un elenco"). Sulla scrivania arriva un solo foglio.
- Secondo il creator, con meno materiale nel contesto Claude resta più "lucido" e riduce il rischio di dimenticare le cose dette all'inizio (il cosiddetto *context rot*).
- Il creator dice che il risparmio riguarda cache, input e output. Per lui l'output è la parte più importante, perché pesa molto sulla spesa.

## Applicalo a un cliente

**Caso: studio professionale con un archivio di note e documenti** (ad esempio un consulente con centinaia di appunti sui clienti).
- **Cosa proponi**: un'automazione che legge tutte le note e produce un elenco unico delle attività ancora aperte. È lo stesso scenario del "company brain" del video.
- **Come la configuri**: attivi Code Mode nelle impostazioni, dai a Claude Code la cartella e un prompt tipo: "Leggi tutte le note, estrai solo le attività aperte e restituiscimi un unico elenco". Per un'automazione continuativa nel cloud, i dettagli di configurazione non sono documentati nelle fonti.
- **Risultato atteso**: meno token per esecuzione e quindi costi più prevedibili. Il risparmio reale va misurato sul caso del cliente: il "fino a 10x" è un'affermazione del creator, non un dato ufficiale.
- **Consiglio**: se l'automazione monitora i consumi, OpenTelemetry è ora compatibile con Code Mode (fatto ufficiale), quindi puoi tenere traccia dei costi.

## Errori comuni e limiti

- **Non conviene sempre**: per domande singole non serve (opinione del creator).
- **Funzione sperimentale**: Anthropic può cambiarla prima del rilascio completo.
- **Il "10x" è del creator**, non ufficiale. Il suo test indica circa 600.000 token in modalità normale, ma il risultato in Code Mode non è nella parte di trascrizione disponibile.
- **Tracing**: con Code Mode resta disattivato; solo eventi e metriche OpenTelemetry sono supportati.
- **Rischio di script fuori controllo**: un ciclo infinito poteva riempire la memoria. Ora c'è un limite, ma serve la v2.1.329 o successiva.
- **Nome della variabile d'ambiente e dettagli desktop/terminale**: non documentati nelle fonti a disposizione.
